## How the Application Works

This Flutter app demonstrates simple page navigation with a product catalog. The home page displays a list of products, including each product's name, description, price, and rating. Tapping a product opens a detail page with larger artwork and the same product information. Use the back button in the app bar or the device's back action to return to the product list.
